## What we build

labs.ayush is a small open-source org based in India, building git tooling that stays close to the metal — no Electron bloat, no cloud lock-in, just fast native tools built with Rust and TypeScript.

## Projects

### 🐧 [Penguin-Git](https://github.com/labs-ayush/Penguin-Git)
A powerful, open-source Git GUI built exclusively for Linux — visual commit graph, interactive rebasing, visual merge conflict resolution, and full repo management without leaving the desktop.

`Rust` · Tauri core + React frontend

### 🔎 [PenguinGit-lens](https://github.com/labs-ayush/PenguinGit-lens)
A lightweight, open-source VS Code extension — inline blame, commit graph, file history, and hover cards, all powered by the PenguinGit Engine.

`TypeScript` · VS Code extension

## Get involved

Issues and PRs are welcome on both repos. If you use Linux and are tired of clunky Git GUIs, Penguin-Git could use your testing and feedback — check the [open issues](https://github.com/labs-ayush/Penguin-Git/issues) to get started.
